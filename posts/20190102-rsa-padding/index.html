RSA公钥加密为什么需要padding

（笔记迁移 @ 2020年）

承接之前讨论的「【提议】使用RSA公钥来安全碰撞用户」中遗留问题，固定padding（或是没有padding）会有什么问题。

本文列举了2种攻击方式。结论是不做padding的RSA有风险，优先考虑其他办法做安全碰撞。

碰撞攻击

没有随机变量参与，RSA公钥加密就是个确定性加密算法。即，输入明文X，输出必定是密文Y，一对一映射关系，这是由数学公式严格界定的。

破解方式，就是创建彩虹表。预先使用公钥加密常见的明文，通过碰撞来解密。

Hastad攻击（广播攻击）

单独看加密公式：y = x^e % n 其中：

  1. x是明文，待求。
  2. y是密文，已知。
  3. (e,n)是公钥，n是已知，e是已知。

现在将一段明文x加密分发给e个用户，假设不同用户e是相同的，取3，但是公钥不同，n不同。（e相同的讨论见下节）

y0 = x^3 % n0
y1 = x^3 % n1
y2 = x^3 % n2

已知，y0y2, n0n2, e，即已知密文，已知用户公钥，求明文x。

代数的方式即可求解。

对上述三个等式变换形式如下，是等价的（k0~k2是整数）：

y0 = x^3 % n0 = x^3 + n0 * k0
y1 = x^3 % n1 = x^3 + n1 * k1
y2 = x^3 % n2 = x^3 + n2 * k2

约去x^3

y0 - y1 = n0 * k0 - n1 * k1
y0 - y2 = n0 * k0 - n2 * k2
y1 - y2 = n1 * k1 - n2 * k2

求解三元方程组，得到k0, k1, k2的值

x = (y0 - n0 * k0) ^ (1/3)

代入k0到任意公式，可得到x。

可见，通过广播攻击，如果RSA不做padding，可获得明文的内容。

（可通过中国剩余定理得出结果，暂未推导出。）

回顾：RSA的定义

参考：https://blog.csdn.net/u010555682/article/details/51901145

1、找密钥的过程 在自然数中找两个大质数p和q，记n=pq，m=(p-1)(q-1)。 在0至m-1的自然数中找一个e,但e要满足1个条件：e与m互素。 再找一个数d，d要满足的条件是：ed-1除以m的余数是0（即ed-1能够被m除尽）。 那么，数字对（e,n）就是公开密钥，数字对（d,n）就是私有密钥。

2、用公开密钥机制加解密的算法公式 注意：在使用公开密钥加密时，明文分组的值要小于n。 假设明文的值是x，密文的值是y。则： 加密公式：密文y=x的e次方除以n的余数 解密公式：明文x=y的d次方除以n的余数

假设：不同的用户share相同的公钥指数

这里有个假设，即，不同用户的公钥指数e是相同的。如果使用Chrome打开服务器证书，可以发现，e都取65537。见下图。

OpenSSL库，e只有两个选择：3或是65537。从加密公式来看，选3，计算效率更高。

-F4|-3 The public exponent to use, either 65537 or 3. The default is 65537.

参考：https://www.openssl.org/docs/man1.1.1/man1/openssl-genrsa.html

结论：不同的用户很大概率都是用相同的公钥指数e，这是由开源库预先定义好的。而每个用户的都有各自的公钥，所以n是不同的（p、q是不同的）。
