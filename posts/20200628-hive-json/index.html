每日同步json文件，建Hive表。

测试数据 comments.json：

{ "blogID" : "FJY26J1333", "date" : "2012-04-01", "name" : "vpxnksu", "comment" : "good stuff", "contact" : { "email" : "vpxnksu@gmail.com", "website" : "vpxnksu.wordpress.com" } }
{ "blogID" : "VSAUMDFGSD", "date" : "2012-04-01", "name" : "yhftrcx", "comment" : "another comment"}

上传数据到HDFS，写入表：

LOAD DATA INPATH '/user/hive/john/comments.json' OVERWRITE INTO TABLE comments;

建外部表：

CREATE  EXTERNAL  TABLE comments
(
blogID STRING,
`date` STRING,
name STRING,
`comment` STRING,
contact STRUCT<email:STRING, website:STRING>
)
ROW FORMAT SERDE 'org.apache.hive.hcatalog.data.JsonSerDe'
STORED AS TEXTFILE
LOCATION '/user/hive/john/test/comments';
