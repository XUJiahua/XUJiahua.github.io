进程、线程、协程

进程有内存地址空间。

进程内可以有多个线程（操作系统线程），线程切换，会有用户态到系统态的切换，是比较“重”的操作。

线程想开多少就开多少，只是 OS 线程切换的开销会很大。多线程能提高CPU利用率，但是过多，超过CPU极限就会产生额外开销。适度，就像吃饭一样。

协程是轻量级线程、绿色线程，由开发语言runtime/lib来维护。M个协程对应到N个线程。

Golang

Java 的多线程是 OS 的多线程，在 Go 中通常情况下是被包裹在 goroutine 和 scheduler 后面的，没见过直接操作线程的。

Clojure (core.async)

Why thread 就是因为没实现抢占式调度。

Go+（放弃了）

https://github.com/goplus/gop

package main

import "time"

func plus1(i float32) float32 {
	return i + 1
}

func double(i float32) float32 {
	return i * 2
}

func main() {
	a := []float32{1, 2, 3.4}

	ch1 := make(chan float32)
	ch2 := make(chan float32)
	ch3 := make(chan float32)

	// double
	go func(in, out chan float32) {
		for e := range in {
			out <- double(e)
		}
		close(out)
	}(ch1, ch2)

	// plus1
	go func(in, out chan float32) {
		for e := range in {
			out <- plus1(e)
		}
		close(out)
	}(ch2, ch3)

	// println
	go func(in chan float32) {
		for e := range in {
			println(e)
		}
	}(ch3)

	// read
	for _, e := range a {
		ch1 <- e
	}
	close(ch1)

	time.Sleep(time.Second)
}
