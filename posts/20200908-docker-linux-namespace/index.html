namespace

Linux 有六大 Namespace（不算 cgroup namespace）。namespace 的作用是为进程在内核层做内核资源隔离。

因为 Docker Image 就是容器要挂载的文件系统，mount namespace（CLONE_NEWNS）默认是开启的，

$ docker run --help
      --pid string                     PID namespace to use
      --userns string                  User namespace to use
      --uts string                     UTS namespace to use
      --network network                Connect a container to a network
      --ipc string                     IPC mode to use

–pid

对应 CLONE_NEWPID 。

默认情况下，启动容器，容器会有独立的 PID namespace。

$ docker run -it busybox sh
/ # ps
PID   USER     TIME  COMMAND
    1 root      0:00 sh
    6 root      0:00 ps

使用 host 的 namespace。

$ docker run --pid=host -it busybox sh
/ # ps
PID   USER     TIME  COMMAND
    1 root      0:05 /lib/systemd/systemd --system --deserialize 18
    2 root      0:00 [kthreadd]
    4 root      0:00 [kworker/0:0H]
    6 root      0:00 [mm_percpu_wq]
    7 root      0:00 [ksoftirqd/0]
    8 root      0:39 [rcu_sched]
    9 root      0:00 [rcu_bh]
   10 root      0:00 [migration/0]

使用其他容器的 namespace。先启动一个 mysqld 容器。

$ docker run -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root -d mysql:5

$ docker ps
CONTAINER ID        IMAGE               COMMAND                  CREATED             STATUS              PORTS                               NAMES
85fa62779aad        mysql:5             "docker-entrypoint.s…"   10 days ago         Up 10 days          0.0.0.0:3306->3306/tcp, 33060/tcp   goofy_chebyshev

使用其他容器 PID NS的格式 --pid=container:<name|id>。

$ docker run --pid=container:85fa62779aad -it busybox sh
/ # ps
PID   USER     TIME  COMMAND
    1 999       1:41 mysqld
  154 root      0:00 sh
  161 root      0:00 ps

–network

对应 CLONE_NEWNET Network namespace。

选择项：

–network=“bridge” : Connect a container to a network ‘bridge’: create a network stack on the default Docker bridge ’none’: no networking ‘container:<name|id>’: reuse another container’s network stack ‘host’: use the Docker host network stack ‘|’: connect to a user-defined network

docker 默认网络一览。

$ docker network ls
NETWORK ID          NAME                DRIVER              SCOPE
1606665681ff        bridge              bridge              local
c61808e357ca        host                host                local
84826bbdb601        none                null                local

–userns

对应 CLONE_NEWUSER。

默认是没有隔离的。需要配置 dockerd 让容器默认 user namespace 隔离 https://docs.docker.com/engine/security/userns-remap/

因为没有隔离，不管复用 host 与否，user namespace 都与 host 一致。

$ readlink /proc/$$/ns/user
user:[4026531837]

$ docker run --userns=host -it busybox sh
/ # readlink /proc/$$/ns/user
user:[4026531837]

–uts

对应 CLONE_NEWUTS。

–ipc

对应 CLONE_NEWIPC。

cgroup

cgroup 的作用是限制资源使用。

$ docker run --help | grep cpu
      --cpu-period int                 Limit CPU CFS (Completely Fair Scheduler) period
      --cpu-quota int                  Limit CPU CFS (Completely Fair Scheduler) quota
      --cpu-rt-period int              Limit CPU real-time period in microseconds
      --cpu-rt-runtime int             Limit CPU real-time runtime in microseconds
  -c, --cpu-shares int                 CPU shares (relative weight)
      --cpus decimal                   Number of CPUs
      --cpuset-cpus string             CPUs in which to allow execution (0-3, 0,1)
      --cpuset-mems string             MEMs in which to allow execution (0-3, 0,1)
      
$ docker run --help | grep mem
  -m, --memory bytes                   Memory limit
      --memory-reservation bytes       Memory soft limit
      --memory-swap bytes              Swap limit equal to memory plus swap: '-1' to enable unlimited swap
      --memory-swappiness int          Tune container memory swappiness (0 to 100) (default -1)

内存

docker run 默认启动，容器默认可使用全部内存。

$ free -g
              total        used        free      shared  buff/cache   available
Mem:              9           1           5           0           3           8
Swap:             0           0           0

$ docker run -it busybox sh

/ # free -g
              total        used        free      shared  buff/cache   available
Mem:              9           1           5           0           3           8
Swap:             0           0           0

$ docker run -m=300M --memory-swap=-1 -it busybox sh
