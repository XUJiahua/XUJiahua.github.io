trait vs. interface & abstract class

面向接口编程。trait 可定义方法签名，也可以有方法的默认实现。

Scala

trait TailWagger {
    def startTail(): Unit
    def stopTail(): Unit
}
  • Use extends to extend the first trait
  • Use with to extend subsequent traits

Java

public interface TailWagger {
    public void startTail();
    public void stopTail();
}

scala abstract class

Java doesn’t know anything about Scala traits, if you want to call your Scala code from Java code, you’ll need to use an abstract class rather than a trait.

// this won’t compile
trait Animal(name: String)

// However, be aware that a class can extend only one abstract class.
abstract class Animal(name: String)

match expressions

类似 Java switch case，但是表达能力更强。

def isTrue(a: Any) = a match {
    case 0 | "" => false
    case _ => true
}

匹配能力非常强。

for expressions

类似于 Python Generator

val nums = Seq(1,2,3)

val doubledNums = for (n <- nums) yield n * 2

Using yield after for is the “secret sauce” that says, “I want to yield a new collection from the existing collection that I’m iterating over in the for-expression, using the algorithm shown.”

Java 啰嗦至极

public class Person {

    private String firstName;
    private String lastName;
    
    public Person(String firstName, String lastName) {
        this.firstName = firstName;
        this.lastName = lastName;
    }
    
    public String getFirstName() {
        return this.firstName;
    }
    
    public void setFirstName(String firstName) {
        this.firstName = firstName;
    }
    
    public String getLastName() {
        return this.lastName;
    }
    
    public void setLastName(String lastName) {
        this.lastName = lastName;
    }
}

companion object

Scala class 没有 class 级的方法、字段。

object SomeClass 类似于 Java class 级方法、字段。

class SomeClass {
    def printFilename() = {
        println(SomeClass.HiddenFilename)
    }
}

object SomeClass {
    private val HiddenFilename = "/tmp/foo.bar"
}

object apply方法，让你不需要使用 new 来创建变量。apply 有点像是一个 factory，创建对象，但这个factory不一定生产比如 Person之类的（object Person的话）。apply 想返回什么类型就返回什么类型，如下。

case class Company(name: String)

class Person(val name: String) {}

object Person {

  def apply(name: String): Company = new Company(name)

}

// this is confusing, but works fine
val c = Person("Bob")
// => Company("Bob"): Company

object unapply方法，让你在 match expressions 里将 class instance 里的值取出来。

case object

case objects are primarily used in two places (instead of regular objects):

  • When creating enumerations
  • When creating containers for “messages” that you want to pass between other objects (such as with the Akka actors library)
