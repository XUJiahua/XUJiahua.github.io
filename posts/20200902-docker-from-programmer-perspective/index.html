就从一个普通程序员角度，讲下 Docker 是什么，在工作上带来了哪些改变。本文作为一个引子给听众一个直接观感，是否能掌握还需听众自发学习。

Docker 是什么

Docker is a platform for developers and sysadmins to build, run, and share applications with containers.

基本使用

参考 https://docs.docker.com/get-started/

底层技术：

  1. （Linux）容器技术。
  2. 分层镜像技术。

https://docs.docker.com/get-started/overview/#the-underlying-technology

容器技术

基于 Linux 内核的虚拟化技术，比起其他虚拟化技术更轻量。

  1. namespace 资源隔离
  2. cgroup 资源控制

分层镜像技术

Image 本质上是容器运行需要的文件系统。

基于 Linux 的联合文件系统，overlayfs。

Docker 分层镜像技术：AUFS/DeviceMapper / overlay

Docker的分层镜像是怎么通过UnionFS这种文件系统做到的，但是，因为Docker首选的AUFS并不在Linux的内核主干里，所以，对于非Ubuntu的Linux分发包，比如CentOS，就无法使用AUFS作为Docker的文件系统了。于是作为第二优先级的DeviceMapper就被拿出来做分层镜像的一个实现。

Union file systems, or UnionFS, are file systems that operate by creating layers, making them very lightweight and fast. Docker Engine uses UnionFS to provide the building blocks for containers. Docker Engine can use multiple UnionFS variants, including AUFS, btrfs, vfs, and DeviceMapper.

https://docs.docker.com/get-started/overview/#union-file-systems

Why Docker (Container)?

https://www.docker.com/resources/what-container

封装的特性带来哪些好处：

  1. 一致性。开发、测试、生产环境可以保持一致。特殊环境引入的问题很耗费时间处理。
  2. 易上手。开发新人、测试人员、运维人员只关注 Docker Image，不必在意其依赖环境。

How to use Docker?

Delete all containers

docker rm $(docker ps -a -q)

Delete all images

docker rmi $(docker images -q)

docker run

-t: 终端

-i: 标准输入

docker run -t -i /bin/bash

docker run: Run a command in a new container

每次都会起一个新的container！

正确的方式：

再次启动container：

docker start <container_id>

连接到这个session：

docker attach <container_id>

打开container的终端：

docker exec -it <container_id> bash

查看运行中的容器：

docker ps

所有容器：

docker ps -a

只显示container id：

docker ps -a -q

查看本地镜像：

docker images

删除Container：

docker rm <container_id>

删除Image：

docker rmi <image_id>

停docker容器：

docker stop <container_id>

Advanced

对于Linux容器的最小组成，可以由以下公式来表示：

容器=cgroup+namespace+rootfs+容器引擎（用户态工具）

其中各项的功能分别为：

  1. Cgroup：资源控制。
  2. Namespace：访问隔离。
  3. rootfs：文件系统隔离。
  4. 容器引擎：生命周期控制。

容器引擎（runc/Libcontainer）是什么：

  1. 通过clone系统调用直接创建容器，
  2. 通过pivot_root系统调用进入容器（今日的容器技术，比如LXC、Docker等，也都是使用了pivot_root来做根文件系统的切换），
  3. 通过直接操作cgroupfs文件实现对资源的管控
