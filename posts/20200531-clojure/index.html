基础类型

List

可以理解为链表。同一个List内元素可以是任何类型。

'(1 2 "jam" :marmalade-jar)
;; -> (1 2 "jam" :marmalade-jar)

其形式跟表达式一样，都是()。为了防止被求值，前面加上'。

常用方法：

first/rest + 递归

Vector

数组，可以index access。

[:jar1 1 2 3 :jar2]
;; -> [:jar1 1 2 3 :jar2]

Map

{:jam1 "strawberry" :jam2 "blackberry"}
;; -> {:jam2 "blackberry", :jam1 "strawberry"}

Set

#{:red :blue :white :pink}
;; -> #{:white :red :blue :pink}

控制逻辑

(defn iftest [x]
  (if x "is true" "is false"))

(iftest true)
(iftest false)

(defn whentest [x]
  (when x "is true"))

(whentest true)
(whentest false)

(defn condtest [x]
  (cond
    (= x "a") "is a"
    (= x "b") "is b"
    :else "what?"))

(condtest "a")
(condtest "b")
(condtest "c")

if = if / else

when = if

cond = if / elseif / else

对应的都是Java里的if啊。
