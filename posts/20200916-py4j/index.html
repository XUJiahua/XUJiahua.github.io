PySpark 是 Spark（JVM 实现） 的 Python 接口。使用 py4j，python 程序可访问 Java 程序。

Py4J

让 Python 程序调用 Java 程序内的对象。解决方式，C/S 结构，通过网络协议通信。

Py4J enables Python programs running in a Python interpreter to dynamically access Java objects in a Java Virtual Machine.

有点类似是 Python 与 Java 之间的 RPC 框架 + 方法类型映射系统。Java 进程启动一个 py4j.GatewayServer 服务器，Python 通过一个 Gateway 对象来连接。

Py4J by default uses the TCP port 25333 to communicate from Python to Java and TCP port 25334 to communicate from Java to Python. It also uses TCP port 25332 for a test echo server (only used by unit tests).

https://www.py4j.org/faq.html#what-ports-are-used-by-py4j

需要考虑两个系统数据类型的序列化和反序列化。

通信记录很多啊。简单的方法操作就有这么多 TCP 包。

有两条通信链路：

  1. Python (py4j.java_gateway) -> Java (py4j.GatewayServer)
  2. Java -> Python

pyspark

The Python driver program communicates with a local JVM running Spark via Py4J.

https://dev.to/steadbytes/python-spark-and-the-jvm-an-overview-of-the-pyspark-runtime-architecture-21gg

PySpark 创建 Python SparkContext

创建子进程 spark-submit，创建一个临时文件，子进程通过环境变量知道临时文件的地址

子进程写入端口号到临时文件

PySpark 进程读取临时文件内容，读取子进程端口号

PySpark 与子进程通信。通过 py4j 框架通信。
