Facebook开源的目标检测库 https://github.com/facebookresearch/detectron2

类似库：

  1. Detectron：Facebook开源。是Detectron2前身，使用Caffe2，不再维护。Detectron2使用PyTorch重写。 https://github.com/facebookresearch/detectron
  2. maskrcnn-benchmark：Facebook开源。不再维护，绑定在PyTorch 1.0了。 https://github.com/facebookresearch/maskrcnn-benchmark
  3. mmDetection：香港中文大学-商汤联合实验室维护。 https://github.com/open-mmlab/mmdetection
  4. SimpleDet： https://github.com/TuSimple/simpledet

参考文章：目标检测三大开源神器：Detectron2/mmDetectron/SimpleDet https://mp.weixin.qq.com/s/jH2xz5l9QnCfWhpaY2rHcA

Detectron2不止目标检测功能。 Detectron2 is Facebooks new vision library that allows us to easily use and create object detection, instance segmentation, keypoint detection and panoptic segmentation models. It has a simple, modular design that makes it easy to rewrite a script for another data-set.

准备工作

CUDA/CuDNN 安装

电脑上已经有Nvidia 1080Ti显卡了。

安装CUDA 10.1工具包（可以理解为Nvidia GPU开放的编程接口，https://zh.wikipedia.org/wiki/CUDA）。例如，我选择了Ubuntu 18.04 本地包。

https://developer.nvidia.com/cuda-10.1-download-archive-base

$ sudo dpkg -i cuda-repo-ubuntu1804-10-1-local-10.1.105-418.39_1.0-1_amd64.deb
$ sudo apt-key add /var/cuda-repo-10-1-local-10.1.105-418.39/7fa2af80.pub
$ sudo apt-get update
$ sudo apt-get install cuda

$ local ll /usr/local/cuda
lrwxrwxrwx 1 root root 9 Apr  4 15:31 /usr/local/cuda -> cuda-10.1

安装CuDNN 7.6.4（NVIDIA cuDNN is a GPU-accelerated library of primitives for deep neural networks.），对应CUDA 10.1版本。下载需要先登录。

下载 https://developer.nvidia.com/rdp/cudnn-archive

安装教程 https://docs.nvidia.com/deeplearning/sdk/cudnn-install/index.html

# Install the runtime library
sudo dpkg -i libcudnn7_7.6.4.38-1+cuda10.1_amd64.deb
# Install the developer library
sudo dpkg -i libcudnn7-dev_7.6.4.38-1+cuda10.1_amd64.deb
# Install the code samples and the cuDNN Library User Guide
sudo dpkg -i libcudnn7-doc_7.6.4.38-1+cuda10.1_amd64.deb

验证安装参考 https://docs.nvidia.com/deeplearning/sdk/cudnn-install/index.html#verify。

PS：遇到一些奇怪的问题，重启就好了。

常见问题

ImportError: libcudart.so.10.0: cannot open shared object file: No such file or directory

因为notebook里，CUDA的版本定为10.0，detectron2的安装版本也是依赖10.0的。

体验（预训练模型）

参考 https://github.com/facebookresearch/detectron2/blob/master/GETTING_STARTED.md

图像推理

# GPU
python demo.py --config-file ../configs/COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x.yaml \
  --input images/*.jpg \
  --opts MODEL.WEIGHTS detectron2://COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x/137849600/model_final_f10217.pkl

# CPU
python demo.py --config-file ../configs/COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x.yaml \
  --input images/*.jpg \
  --opts MODEL.DEVICE cpu \
  MODEL.WEIGHTS detectron2://COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x/137849600/model_final_f10217.pkl

GPU推理：

CPU推理：

GPU推理一张图大概0.2s。如果使用CPU推理，就是2s这个级别了。图中没有显示的是，CPU推理一张图，需要占用一半的CPU核心。

视频推理

python demo.py --config-file ../configs/COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x.yaml \
  --video-input driving.mp4 \
  --opts MODEL.WEIGHTS detectron2://COCO-InstanceSegmentation/mask_rcnn_R_50_FPN_3x/137849600/model_final_f10217.pkl

使用GPU，视频效果不流畅。也好理解：按照图像推理0.2秒一张图计，1秒处理5张。也就是视觉上1秒看到5次画面变化，明显是不流畅的，视频至少要满足1秒24个帧（frame）吧（允悲）。还有改进空间，可以看到，GPU没被充分利用，完全可以通过并行处理多个frame，来提高流畅性。

使用Docker体验Detectron2（CPU） https://mc.ai/detectron2-the-basic-end-to-end-tutorial/

code https://github.com/ylashin/detectron2-tutorial

# 启动容器
$ docker run --name detectron2_cpu -p 5000:5000 -d ylashin/detectron2:latest

容器内下载模型失败

# 容器内下载模型，非常容易失败
$ docker logs detectron2_cpu
model_final_f6e8b1.pkl:   6%|▌         | 14.2M/243M [10:18<2:45:55, 23.0kB/s]
Failed to download https://dl.fbaipublicfiles.com/detectron2/COCO-Detection/faster_rcnn_R_101_FPN_3x/137851257/model_final_f6e8b1.pkl

需要科学地手动下载 https://dl.fbaipublicfiles.com/detectron2/COCO-Detection/faster_rcnn_R_101_FPN_3x/137851257/model_final_f6e8b1.pkl

并挂载到容器内，/root/.torch/fvcore_cache/detectron2/COCO-Detection/faster_rcnn_R_101_FPN_3x/137851257/model_final_f6e8b1.pkl

$ docker run --name detectron2_cpu \
	-v `pwd`/model_final_f6e8b1.pkl:/root/.torch/fvcore_cache/detectron2/COCO-Detection/faster_rcnn_R_101_FPN_3x/137851257/model_final_f6e8b1.pkl \
	-p 5000:5000 -d ylashin/detectron2:latest
