原文：Ray for the Curious

这篇文章是对Ray的一个大体介绍，Ray解决了哪些问题。我本身已经有点印象了，不想多看。

大数据 MapReduce 模型适合数据清洗和数据分析，但是不适合机器学习任务。

机器学习任务需要工作粒度可控，细粒度、粗粒度都得支持好。举个例子吧？

The original MapReduce model for big data workloads works well for data cleaning, preparation, and also for analysis workloads, but machine learning workloads require a mixture of fine-grained to coarse-grained tasks, along with varied communication patterns between components.

分布式不断变化的状态。

A second challenge is distributed, evolving state. In the context of ML/AI, distributed state includes the hyperparameters, model parameters used for training.
