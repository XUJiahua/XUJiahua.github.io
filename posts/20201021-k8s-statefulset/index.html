StatefulSet 简介

不同于 Deployment 类型用于无状态服务，StatefulSet 在 Deployment 基础上通过存储来持久化状态。

The Pods’ ordinals, hostnames, SRV records, and A record names have not changed, but the IP addresses associated with the Pods may have changed. In the cluster used for this tutorial, they have. This is why it is important not to configure other applications to connect to Pods in a StatefulSet by IP address.

概念厘清

云盘：比如阿里SSD云盘

PV = PersistentVolume：PV是K8S的存储概念，云盘可以映射到PV。由管理员创建，或者由动态provision。

PVC = PersistentVolumeClaim：PVC用于申请PV资源

A PersistentVolume (PV) is a piece of storage in the cluster that has been provisioned by an administrator or dynamically provisioned using Storage Classes. It is a resource in the cluster just like a node is a cluster resource. PVs are volume plugins like Volumes, but have a lifecycle independent of any individual Pod that uses the PV. This API object captures the details of the implementation of the storage, be that NFS, iSCSI, or a cloud-provider-specific storage system.

A PersistentVolumeClaim (PVC) is a request for storage by a user. It is similar to a Pod. Pods consume node resources and PVCs consume PV resources. Pods can request specific levels of resources (CPU and Memory). Claims can request specific size and access modes (e.g., they can be mounted ReadWriteOnce, ReadOnlyMany or ReadWriteMany, see AccessModes).

https://kubernetes.io/docs/concepts/storage/persistent-volumes/

StorageClass：在PVC中指定，用于动态创建

Provisioner：创建StorageClass时指定。托管集群默认安装了 CSI 插件。https://developer.aliyun.com/article/745953 每个云厂商都会创建这样一个插件。https://github.com/kubernetes-sigs/alibaba-cloud-csi-driver/blob/master/docs/disk.md 插件名称 diskplugin.csi.alibabacloud.com

PersistentVolume（PV）是一块集群里由管理员手动提供，或 kubernetes 通过 StorageClass 动态创建的存储。 PersistentVolumeClaim（PVC）是一个满足对 PV 存储需要的请求。PersistentVolumes 和 PersistentVolumeClaims 是独立于 Pod 生命周期而在 Pod 重启，重新调度甚至删除过程中保存数据。

Dynamic Volume Provisioning

The implementation of dynamic volume provisioning is based on the API object StorageClassfrom the API group storage.k8s.io. A cluster administrator can define as many StorageClass objects as needed, each specifying a volume plugin (aka provisioner) that provisions a volume and the set of parameters to pass to that provisioner when provisioning.

阿里云

云盘使用限制：

推荐使用StatefulSet挂载使用云盘，Deployment挂载云盘时Replica需要为1。

云盘为阿里云存储团队提供的非共享存储，只能同时被一个Pod挂载。

集群中只有与云盘在同一个可用区（Zone）的节点才可以挂载云盘。

https://help.aliyun.com/document_detail/86784.html?spm=a2c4g.11186623.6.774.7f4a49a2Aims4i
