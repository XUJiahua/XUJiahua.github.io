Hive：

  1. MapReduce的抽象，关注SQL，而不是写Mapper/Reducer。
  2. 文件的schema映射。CSV格式到表结构，JSON格式到表结构，还有正则等格式。

原始文件，可以直接被当做一张表来处理。使用SQL来处理数据，不再需要面向过程编程。使用集合、声明的思想、方式做开发。

Impala没法直接使用，需要将其转储为其他格式。

HDFS存储原始数据，MySQL存储元数据。

select * from ods_dks_yz_order;

show partitions ods_dks_yz_order;

有时候通过HDFS命令直接同步了数据文件，而没有更新元数据，使用如下命令同步下。

MSCK REPAIR TABLE ods_dks_yz_order;

或是就是使用LOAD命令加载数据，这样同时上传文件并更新元数据。

hive-hcatalog-core.jar放入${HIVE_HOME}/auxlib目录。需要重启HiveServer。

ansible all -i hosts.ivt -m shell -a "ln -s /opt/cloudera/parcels/CDH-6.3.2-1.cdh6.3.2.p0.1605554/jars/hive-hcatalog-core-2.1.1-cdh6.3.2.jar /opt/cloudera/parcels/CDH/lib/hive/auxlib/hive-hcatalog-core-2.1.1-cdh6.3.2.jar"
