下载Anki很久了，今天好好用下。

Anki

下载安装：https://apps.ankiweb.net/ 。

基本概念：

MDAnki - Converts Markdown file(s) to the Anki cards.

闪卡制作工具，将Markdown文件转成Anki闪卡。地址：https://github.com/ashlinchak/mdanki

安装

npm install -g mdanki

算法闪卡制作

An Open-Source Collection of +200 Algorithmic Flash Cards to Help you Preparing your Algorithm & Data Structure Interview https://github.com/teivah/algodeck


git clone https://github.com/teivah/algodeck.git

rm algodeck/README.md # 不是闪卡一部分

mdanki --deck algodeck ./algodeck algodeck.apkg # algodeck.apkg双击打开，进入Anki界面
